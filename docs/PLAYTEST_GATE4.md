# Gate 4 Playtest Result — NULL//SHIFT Vertical Slice

**Date:** 2026-10-02
**Tester:** Lucas (first-time player of this build; project owner)
**Build:** Gate 4 slice, rooms 1.1 + 1.2, source run on Windows
**Protocol:** `docs/PLAYTEST_PROTOCOL.md` (timings below are qualitative —
the protocol's numeric fields were reported qualitatively)

## Observed result

1. **Room 1.1 comprehension:** immediate / straightforward. Movement,
   console interaction and exit were understood without friction.
2. **Room 1.2 echo comprehension:** fast. The player grasped that the
   reset preserves their previous run as a cooperating echo and solved
   the plate/door puzzle with it.
3. **Reset feeling:** somewhat strange (reported qualitatively; no
   specific confusion, more a "this feels odd" note — worth watching,
   not a defect).
4. **Echo playback:** worked correctly. No desync, no confusion between
   echo and player reported.
5. **Blocking bugs / confusion:** none reported.
6. **Main weakness:** the prototype feels visually and systemically rough
   and lacks world, story, characters and atmosphere.
7. **Core echo mechanic:** interesting / **approved**.

## Interpretation (recorded, not editorialized)

This is **not a failed slice**. The Gate 4 criterion — the temporal-echo
mechanic is comprehensible and functional for a first-time player — is
**satisfied**. What the playtest exposed is a **creative-direction gap**,
not a mechanic defect: the slice proves the verb, but there is no world
for the verb to live in. Phase 4.5 (creative direction adoption +
architecture delta) exists to address exactly this.

## Consequences

- Gate 4 remains **APPROVED WITH CONDITIONS**; the remaining condition
  (first-time-player validation) is now **discharged** by this result.
- The "reset feels somewhat strange" note is carried as a watch item for
  Gate 5 polish (presentation: flash, sound, echo-spawn effect) — not a
  mechanic change.
- Content production (Gate 5) is unblocked **pending Lucas's approval of
  the Phase 4.5 D016–D018 delta**.
